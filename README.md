# 💎 Diamond Construction

> **Building Beyond Boundaries** — Official website for Diamond Construction, a Mangalore-based residential & commercial construction company.

🌐 **Live Site:** [mohdhafeez07.github.io/diamond-construction](https://mohdhafeez07.github.io/diamond-construction)

---

## Tech Stack

| | |
|---|---|
| **Framework** | React 19 + Vite 7 |
| **Styling** | TailwindCSS 3 |
| **Animations** | Framer Motion 12 |
| **Routing** | React Router DOM 7 |
| **Icons** | Lucide React + React Icons |
| **Deployment** | GitHub Pages (`gh-pages`) |

---

## Pages

| Route | Description |
|---|---|
| `/` | Home — Hero carousel, About teaser, Upcoming project, Why Choose Us, Testimonials |
| `/about` | Company story, mission, values, certifications |
| `/projects` | Portfolio of 4 projects (Diamond Avenue, Queen, Habitat, Arcade) |
| `/contact` | Phone, WhatsApp, Email + Google Maps office embed |

---

## Quick Start

```bash
# Install dependencies
npm install

# Run dev server (http://localhost:5173)
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
